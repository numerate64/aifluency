# AI Fluency

A browser-only, responsive learning site for teenagers and adults. The original curriculum moves from AI 101 foundations to 201 collaboration skills and 301 human-centered workflow design.

## Run locally

Open `index.html` directly, or serve the folder with any static web server. There is no build step, account, backend, or tracking. Lesson progress is stored locally in the browser using `localStorage`.

## Learning approach

The curriculum is original and tool-agnostic. Its competency compass is inspired by Anthropic's published AI Fluency Framework (Delegation, Description, Discernment, and Diligence). This independent project is not affiliated with or endorsed by Anthropic. Learners are encouraged to follow school, workplace, and AI-tool policies.

## Files

- `index.html` — page structure and accessible course dialogs
- `styles.css` — responsive visual system
- `app.js` — course content, lesson navigation, check-in, local progress
